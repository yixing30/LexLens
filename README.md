# LexLens 本地 Chrome 扩展

根据 [PRD.md](PRD.md) 开发，在普通英文网页的可读取文字上按所选等级显示生词的中文释义。无需上架 Chrome 应用商店，也无需网页端账号。

## 安装和更新

1. 运行 `npm run build:extension`，得到安装目录 `dist/LexLens-Chrome`。
2. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择整个 `dist/LexLens-Chrome` 文件夹。
3. 打开或刷新英文网页，点击 LexLens 图标，确认英语已开启并选择 A1–C2 等级。弹窗显示当前网页的“上方释义”数量。
4. 以后修改扩展文件时，重新运行构建命令，点击扩展管理页中的 LexLens 刷新按钮，再刷新网页。已安装的扩展不需要重新选目录。

在扩展弹窗中开启“网页浮动按钮”后，页面右下角会出现“译”按钮。点击可快速调整英语开关、等级、标注密度，重新扫描或打开独立阅读视图；上下拖动可调整高度，位置保存在本机。再次关闭该开关即可移除按钮。

如果没有标注，先打开扩展弹窗中的“标注自检页”；若自检页正常，检查 Chrome 扩展详情中的“在所有网站上”访问权限，并在目标网页点击“重新扫描”。浏览器内部页面、PDF、图片文字和封闭 Shadow DOM 无法原位标注。Codex 内置浏览器不会运行 Chrome 扩展。

## 英语标注方式

- 每个网页使用同一套本地词表和词典，不保存任何文章专属释义。切换等级会重算当前网页；打开新英文网页也会自动标注。
- 默认“词表分级”采用 CEFR-J A1–B2 与 Octanove C1/C2 的词形和词性等级。对高于所选等级的词，优先使用少量人工语境规则；其他有词典释义的词，在原词上方显示 ECDICT 常见义。不对原词额外高亮或加下划线。
- 多词性词条采用各词性中最低的可靠等级作为自动标注下限：只有该下限高于当前等级时才默认标注，避免遗漏所有词性都超等级的词。弹窗中的“也显示所选等级词汇”可额外标注同级词；主动选词查词后，可用“仍不认识，标注此词”将该词加入个人标注。
- “包含粗略估计”会额外按 ECDICT 词频推测缺少词表等级的词，并显示其中文释义。词频映射不是正式 CEFR 分级。
- 点击上方释义可查看完整本地词典条目，并标记“已认识”或“仍不认识”。个人记录和设置只保存在浏览器本机，不绑定网站，也不上传网页文字。
- 在网页上选中英文单词会直接打开“查词与翻译”面板，显示中英词典释义、词性、音标、网页原句，并可点击英式或美式发音；选中句段可翻译整段。触屏长按单词也可打开面板。所有桌面系统使用浏览器内置的本地 Translator API；首次使用可能需要在面板点击“下载并翻译”以下载语言包。若浏览器或设备不支持，面板会显示原因，查词仍可使用。
- 查单词时面板默认显示简短中文释义，切换“词典 / 翻译”标签查看对应内容；英文释义、例句、等级与学习记录可按需展开。词典未收录的单词会优先展示网页原句的本机中文翻译，作为语境参考，不冒充逐词词典义；词典文件读取失败时可重试。选中句段则直接显示翻译。点击面板外或按 Esc 可关闭。窄屏使用底部面板，桌面端限制面板高度并允许内部滚动。
- 行间释义只检查当前可见部分的真实裁剪情况；在网页边缘会自动调整位置。只有仍被页面裁剪或与同一段落的释义重叠时，才提示使用独立阅读视图。
- Chrome 的英中翻译语言包由浏览器管理，macOS 模型目录为 `~/Library/Application Support/Google/Chrome/TranslateKit/models/`；可在 `chrome://on-device-translation-internals/` 查看 `en - zh` 是否已安装。此目录不属于 LexLens 扩展安装文件夹。
- 词典短义没有逐句消歧。多义词、隐喻和专业术语可能显示不符合当前句子的意思；点击词语可核对完整词典。扩展不宣称已经达到 PRD 的逐句释义准确率。

英语等级词表共 8,148 个词形，其中 7,866 个具有可用于行间显示的本地 ECDICT 中文短义。约 41,353 个 ECDICT 词条支持主动查询。当前扩展仅展示和运行英语模块；日语、韩语原型代码暂时保留，旧设置也不会使其运行。

## 开发与数据来源

运行 `npm test` 和 `npm run check` 验证代码。`demo/try.html` 可在本地服务器中单独演示同一套标注逻辑。短义由 [scripts/build_inline_glosses.py](scripts/build_inline_glosses.py) 从已有的本地词典提取，不针对任何网站写规则。若重建 ECDICT 数据或等级索引，应再次运行该脚本。

英文释义来自 [ECDICT](https://github.com/skywind3000/ECDICT)，许可和来源见 [data/NOTICE.md](data/NOTICE.md)。英语等级词表来源见 [data/ENGLISH-LEVELS-NOTICE.md](data/ENGLISH-LEVELS-NOTICE.md)。上游词典虽以 MIT 许可发布，其词条来自多个早期来源；公开再分发前应进一步核查。
